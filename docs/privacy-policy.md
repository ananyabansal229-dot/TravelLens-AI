# TravelLens AI – Privacy and Data Handling

## Principles

TravelLens AI will follow privacy-conscious development
practices.

## Camera Permissions

Camera access will be requested when users use landmark
recognition.

## Location Permissions

Location access will be requested when users use nearby
landmark discovery or navigation.

## User Information

Only information required for the application's
functionality will be collected.

## Community Contributions

User-submitted photographs, stories, and facts will be
reviewed before public publication.

## Analytics

Analytics will use aggregated or appropriately
de-identified information wherever possible.

## User Control

Users should be able to manage saved information and
control optional data sharing.

## Security

Appropriate authentication, authorization, secure
communication, and access controls will be implemented.

This document describes intended practices and is not
a substitute for a finalized legal privacy policy.
